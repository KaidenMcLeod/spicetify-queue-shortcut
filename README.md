Adds a add to queue keyboard shortcut. Either hover over a single song and press the keybind to add it to the queue, or select multiple songs using shift/ctrl and press the keybind to add them all to queue. 

Default keybind is 'Q'. Customise the keybind by clicking your profile icon in the top right, then select "Add to queue shortcut keybind".

Requires spicetify, install using spicetify's marketplace.
